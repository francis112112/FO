# FO
A  little app made by c and python that organizes files by filename keywords, featuring animated robot couriers and integrated tests.
$ README
After open the app, I recommend to click the test lab to test whether the app can work successfully on the computer. Then, click the sorting rules on the left to choose which key word you wanna get. Then go back to transfer and choose the input/output path. Finally scan the files and remove selected files to the destination file you want.
